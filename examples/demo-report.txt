  [CRITICAL] Sessions start with permission prompts disabled
      permissions.defaultMode = bypassPermissions  —  ~/.claude/settings.json
      Why: Every session starts in `bypassPermissions` mode: Claude Code runs commands, edits files (including `.git` and `.claude`) and calls tools without asking. Anthropic recommends this only inside isolated containers or VMs.
      Fix: Remove the setting and use `--permission-mode bypassPermissions` only for sessions inside a sandbox. Consider `permissions.disableBypassPermissionsMode: "disable"`.
  [CRITICAL] No sandbox and no approvals
      sandbox_mode = danger-full-access, approval_policy = never (profile: yolo)  —  ~/.codex/config.toml
      Why: Codex runs every command with full filesystem and network access and never asks first. Any prompt injection becomes code execution as your user.
      Fix: Use `workspace-write` (the default sandbox) and reserve `danger-full-access` for disposable containers.
  [CRITICAL] Credential written directly in the config file
      postgres  —  ./.mcp.json
      Why: A value in command arguments looks like a literal credential. It is stored in plain text in a file meant to be committed to the repository, ends up in backups and screen shares, and is readable by any process running as you. The value is not shown in this report.
      Fix: Move the value to an environment variable or the client's secret input (for example `${env:NAME}` or `${input:id}`), then rotate the credential.
