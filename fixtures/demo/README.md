# Demo fixtures

A fictional project (`acme-api/`) and a fictional home directory (`home/`) used by
`agent-permission-map demo`, the golden-report test and the examples in `examples/`.

Every credential-looking value here is fake and deliberately not shaped like a real
token, so these files do not trip secret scanners. `home/.codeium/windsurf/mcp_config.json`
is intentionally malformed.
